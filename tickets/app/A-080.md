## The work

1. **`src/services/uncharted/duel.ts` — `unchartedConfig(doc, captain)`**: builds a legal
   `DuelConfig` with `islandId: 'grandline'` as the legality anchor, `enemyMaxHull: doc.hull`
   (the `buildCore` override, `src/engine/duel/types.ts:86,210`), `duelId:
   'gduel_<index>_<seed36>'`, the same `inBandLoadout` player filter the real boot applies
   (`src/stores/duel.ts:196-201`), and `rivalLoadout` derived from `doc.skills` mapped to
   in-band cannons (the `rivalLoadout.ts` derivation pattern, WITHOUT `islandCurriculumFor`).
   Do NOT touch `legacyConfig` — its `templatesBySkill: TEMPLATE_POOLS` line is source-pinned.
2. **`app/duel.tsx` gen branch**, keyed on an explicit uncharted boot flag (set by the entry
   action, never a route param — the no-route-params law): HUD island name = `doc.displayName`
   (never the anchor's minted name from `state.islandName`); rival presentation from
   `doc.presentationKind` + the dealt fleet doc (`doc.rivalDocId` → the shipped 20-doc pool's
   renderer, bypassing `getEnemyForIsland`/`rivalVariantFor`, which throw on gen ids); crew via
   `crewFor(doc.rivalDocId)`; per-turn rival loadout from the doc. The authored branch and
   `resolveDuelContext` stay byte-untouched.

- **AC-1**: `unchartedConfig` output passes `validateConfig` for every 30-seed × 3-band sweep
  of A-078 docs; the built core's `enemyMaxHull === doc.hull`; same doc + same seed → the
  identical question sequence (determinism retained as test infrastructure per D-15).
- **AC-2**: The ceiling holds in the tray — every player gun and every rival gun in a gen
  config sits at or under the band's ceiling; a k_1 gen duel never renders ×/÷ (the A-060
  restatement, swept).
- **AC-3**: The screen never leaks the anchor: with the gen flag set, the rendered HUD name
  equals `doc.displayName` and never equals the Grandline's band name (AST/source-guard plus
  behavioral spec).
- **AC-4**: The authored path is byte-identical — `resolveDuelContext`, `legacyConfig`, and
  every existing duel spec (A-014/A-058 seed pins, duel-outcome, grade-band-duel) pass
  UNTOUCHED; a captain without the gen flag cannot reach the branch.
