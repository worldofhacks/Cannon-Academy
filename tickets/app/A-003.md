## Context

Three routes exist and none guard their preconditions. Onboarding pushes straight into a duel
because the chart does not exist; a returning captain is shown the title again; a duel entered
without a grade band silently defaults to K-1.

This ticket is the decision, as a pure function of captain state — deliberately not a hook and not
a component, so it is testable headless and there is exactly ONE place that decides.

## Acceptance Criteria

- **AC-1**: Given a captain with `hasCompletedOnboarding: false`, when the destination is resolved,
  then it is the grade picker.
- **AC-2**: Given a captain who has picked a band but has no name, when resolved, then it is the
  name/flag screen.
- **AC-3**: Given a captain who completed onboarding, when resolved, then it is the sea chart —
  never the title and never onboarding.
- **AC-4**: Given a captain who has not fought the guided duel, when resolved after onboarding,
  then it is the guided duel exactly once.
- **AC-5**: Given any captain state whatsoever, when resolved, then the result is one of the
  declared destinations — the function is total.
- **AC-6**: Given a captain with an empty `equippedCannons`, when a duel destination is requested,
  then it resolves to the gun deck instead of an unplayable duel.

## Test Plan

- Unit (deterministic): every AC, plus an exhaustive sweep over the cartesian product of the
  boolean captain flags asserting totality (AC-5).
