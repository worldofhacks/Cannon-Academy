## Context

`ranks.json` ships five tiers and `rankTierForWins` is a complete, tested engine function. Neither
reaches a screen, so the competitive frame PLAN.md describes does not exist for the player.

## Acceptance Criteria

- **AC-1**: Given a captain's wins, when the ladder renders, then the current tier comes from
  `rankTierForWins` and the next tier's requirement is stated.
- **AC-2**: Given a loss, when the ladder renders, then the tier is unchanged from before it.
- **AC-3**: Given per-skill mastery, when progress renders, then each skill's meter reflects the
  stored value and its unlock threshold.
