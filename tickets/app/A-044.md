## Context

The application was deployed and recorded, but the repository landing documents still describe
the pre-build plan as current state. `README.md` reports old waves and pre-flight work,
`HANDOFF.md` is a deadline snapshot from before the final deployment, `RELEASE.md` is primarily a
phone-build note, and historical ticket tables compete with ticket frontmatter. The repository
also has both GitHub and GitLab remotes while an old document says there is no remote, and its
blank raw-asset directories and absent design-board artifact do not support blanket claims about
the provenance or licence of the PNG files that actually ship. The hand-seeded canonical index is
itself stale at `57563ce` / 2,065 tests, says T-036 is pending, and omits A-042/A-043; A-035 first
replaces it with generated truth. This ticket then creates a truthful reviewer-facing baseline
without deleting the planning and release history that explains how the build was produced.
