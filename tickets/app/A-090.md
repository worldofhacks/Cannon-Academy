## Ruling

**D-19**: a wreck is "a one-off duel with a bigger chest and no rank consequence — the
map's side quest"; a rival-at-sea is a repeatable fight with honest met-marking and no
voyage consequence. **DO NOT START until A-089 is landed.**

## The work

`src/services/waypointDuel.ts` on the A-080 anchor pattern (the frontier proved the shape —
reuse it, don't reinvent): a waypoint duel boots through the nearest island's REAL id (its
band-true content is exactly right — this is an authored-sea fight, not a gen island),
rival dealt deterministically from the shipped fleet pool per (waypointId, visitCount),
duelId `wduel_<id>_<n>`. Settlement via `settleDuelRewards(store, core, {voyage:'hold'})`
— mastery and coins are REAL (practice that pays), voyage never moves, and the fought
fleet ship marks met honestly (the default `fleet:'mark'` is wrong here because the island
derives the WRONG ship — pass `fleet:'hold'` and mark `doc id` explicitly, the A-081
pattern). Wreck pays one chest tier above the local island's; rival-at-sea pays the
standard tier. Both repeatable: each visit a fresh receipt key (`duel:wduel_<id>_<n>`),
found-state latched via A-089 on first fight. The `app/duel.tsx` branch rides the SAME
boot flag family A-080 landed — the authored and gen branches stay byte-untouched.

## Acceptance criteria

- **AC-1**: A wreck win pays exactly one chest at +1 tier, receipted, idempotent per visit
  index; rank points DO move mastery tallies but `currentIsland`/`unlockedIslands`/
  `chartProgress` are deep-equal before vs after (no voyage strings attached, swept both
  kinds × 3 bands).
- **AC-2**: Honest met — the actually-fought fleet doc id lands in `metRivals`; the local
  island's authored ship does NOT (unless it was the dealt ship); loss marks nothing.
- **AC-3**: Band safety — every question in a waypoint duel sits under the captain's
  ceiling (the boot inherits the island's band-true loadout law; k_1 never sees ×/÷,
  swept).
- **AC-4**: The frozen duel suites (A-014/A-058 pins, duel-outcome, grade-band-duel,
  uncharted-duel) pass UNTOUCHED; without a waypoint boot flag the branch is unreachable.
