## Context

The range correctly reuses the duel's `QuestionPanel`, but that shared panel forces every prompt
into a 56pt-high row at 44pt type. Short arithmetic fits; authored word problems and two-step
prompts do not, so native clips the question a child must answer. The reference says the question
band is shared, not that every prompt has one-line operator typography.

## Acceptance Criteria

- **AC-1**: Given every authored question template used by duel or range, when its rendered prompt
  is classified, then short arithmetic retains the 44pt display treatment while longer or
  sentence-like prompts receive a bounded multi-line treatment that fits the shared question band.
- **AC-2**: Given a long Practice prompt on the narrowest supported 360×640 layout, when
  `QuestionPanel` renders it, then the full prompt is available in at most the configured line
  count with font shrinking/wrapping enabled rather than clipped by a fixed one-line height.
- **AC-3**: Given any fitted visual treatment, when accessibility reads the question, then it
  receives the original full prompt with no truncation or rewritten arithmetic.
- **AC-4**: Given the same shared component in a real duel, when a short arithmetic prompt renders,
  then the fuse and four-choice grid retain their existing layout and tap targets.

## Test Plan

- Unit (deterministic): pure typography classification across every authored template and explicit
  short/long boundaries.
- Source contract (deterministic): `QuestionPanel` applies the classifier, a bounded multiline
  contract, native font fitting, and the full accessibility label.
- Native smoke (release evidence): the longest available Practice prompt at 360×640 and on the
  current iPhone simulator, plus one short duel prompt.
