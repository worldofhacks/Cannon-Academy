## Context

`app/guided-duel.tsx` is a 23-line stub written only to stop `flow.ts` routing a captain into a
missing route. A child finishing onboarding today lands on a placeholder.

**This ticket was missing from the plan entirely.** It appeared only as a destination string in
A-003. The adversarial plan review the skill calls for — the step that finds "a requirement no
ticket traces to" — was not run, and this is what it would have caught.

The engine side is ready and unused: T-018 ships a scripted rival, and `ONBOARDING_ENEMY_HULL = 28`
is tuned so the sloop "politely sinks in three volleys" against the Swivel Gun's guaranteed floor.

**The owner's framing, which governs the scope:** the audience is kindergartners, so this is not a
difficulty setting — it is the only place the mechanic is ever taught. A child who leaves this
screen not knowing that _answering the question is what fires the cannon_ has not been taught
anything, however gently they won.

## Acceptance Criteria

- **AC-1**: Given a captain who has not fought it, when they finish onboarding, then the guided duel
  is their destination, and it is entered exactly once for the life of the captain.
- **AC-2**: Given the guided duel, when it starts, then the rival is the scripted opponent from
  T-018 and its hull is `ONBOARDING_ENEMY_HULL` — no literal in the app layer.
- **AC-3**: Given any sequence of answers, including all wrong and all timed out, when the duel
  runs, then the player's hull never reaches zero. Losing the first duel is the worst first
  impression this game can make.
- **AC-4**: Given the guided duel completes, when it resolves, then `hasFoughtGuidedDuel` is true,
  it persists, and the captain lands on the sea chart.
- **AC-5**: Given the guided duel, when a wrong answer is given, then the correct answer is shown
  before the turn passes — the teaching moment is not optional here.
- **AC-6**: Given the guided duel, when rewards resolve, then they apply exactly once, exactly as a
  real duel does — a tutorial that pays differently teaches the tutorial.
- **AC-7**: Given the guided duel has been fought, when the captain relaunches, then they are never
  routed back into it.

## Test Plan

- Unit (deterministic): every AC. The scripted opponent is seeded and the reward path is already
  covered by A-008's frozen suite, so all of this runs headless.
- Property (deterministic): AC-3 swept over an exhaustive answer-pattern space — all-correct,
  all-wrong, all-timeout, and mixed — asserting hull > 0 throughout. A hand-picked case would miss
  the pattern that sinks them.
- Visual (posture-gated): the coaching affordance, verified by screenshot per `.tdd-swarm/posture.md`.
