## Ruling

**D-19**: waypoints are optional, repeatable and cheap — only islands gate progress. **DO
NOT START until A-088 is landed** (it renders what you make live).

## The work

1. **Waypoint catalog** in `src/services/waypoints.ts`: the board's eleven rows (id, kind
   buoy/chest/wreck/rival/rock, position key) as content data; kinds `rock` are inert by
   type. Waypoint ids live in their OWN namespace (`wp_*`) — never in any island field.
2. **Found-state**: captain gains tolerated-as-absent `waypoints?: { found: string[] }` —
   the exact A-079 pattern (default in emptyCaptain, normalize + migrate arms, corrupt →
   fresh, ids filtered to the catalog, NO SCHEMA_VERSION bump). "Found" = first interaction.
3. **Buoy**: resolves to the existing practice-range door for the nearest island's band-true
   drills — a router, zero new drill logic.
4. **Chest**: a one-time coin pickup per chest — receipted through the existing grant
   grammar (`waypoint:<id>` receipt key), idempotent, coins at encounter scale; opened
   chests render found/emptied via A-088's states.
5. **Counter truth**: `discoveredCount(captain)` = cleared islands + found waypoints,
   feeding A-088's "N OF 16 FOUND" pill.

## Acceptance criteria

- **AC-1**: The found-state round-trips the persistence gauntlet (absent-tolerated, corrupt
  → fresh, unknown ids dropped); the frozen persistence suite passes with only additive
  specs.
- **AC-2**: A chest pays exactly once — double-tap and re-hydrate replay both no-op
  (receipt-idempotent), coins within encounter scale, deep-equal captain otherwise.
- **AC-3**: Buoy resolution returns the same range destination the dock's Practice verb
  yields for that island — proven by delegation equality, no forked drill list.
- **AC-4**: Rocks are unrepresentable as interactions (type-level + runtime no-op spec);
  islands' progression state is byte-untouched by any waypoint action.
