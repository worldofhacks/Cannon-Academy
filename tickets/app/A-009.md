## Context

Mastery has two fill rates and the app implements neither. The range is the full-rate lane and the
only reason the meter moves fast enough to unlock anything inside a demo.

PLAN.md sets the cut line explicitly: **reuse the duel question UI against a stationary target buoy
— a meter, not a new mode.** That is the scope. Anything more is a second duel screen.

## Acceptance Criteria

- **AC-1**: Given an island's `rangeSkills`, when the range opens, then only those skills are
  drillable.
- **AC-2**: Given a correct answer in a drill, when it is recorded, then mastery rises at the full
  rate — twice the duel rate.
- **AC-3**: Given a drill session, when it ends, then the mastery gained persists.
- **AC-4**: Given a meter crossing threshold at or above the accuracy floor, when the session ends,
  then the cannon unlock fires and the next island's fog lifts.
- **AC-5**: Given a wrong answer in a drill, when it is recorded, then no hull, coins or rank are
  affected — a range is practice, and practice cannot cost anything.
