## The screen — 402×874, three states

Transcribe the board into `unchartedBoard.ts` constants (the `board.ts` transcription
discipline — measured, not invented):

1. **Header**: harbor chip (52px), title pill "The Uncharted Sea" + depth label
   (`ISLAND {index} · FOG PARTING / UNCLAIMED / CLAIMED`), coins pill reading the purse.
2. **Storm wall ahead** (top 236px): three storm blobs (state-tinted per board), ghost ship
   at state opacity, two bolts, ahead-label pill (`SOMETHING IS OUT THERE` / `NEXT ISLAND —
   NOT YET` / `THE FOG IS STIRRING`), wall stir on victorious.
3. **Center island** (`IslandFigure`): recipe geometry + pieces + mood from the A-078 doc —
   the four recipes and ten pieces exactly as the board's ISLANDS table and kit rows draw
   them; marker disc (56px, state bg, glyph = `SKILL_GLYPH[skills[0]]`), name banner
   (19px Baloo pill, max-width per board, ellipsize never wrap), skill chip, ship-01 sprite
   at the state position, arriving fog-part animation (620ms, the two halves), ready glow +
   marker rings, victorious green marker.
4. **Tally panel**: `ISLANDS BEHIND YOU` + `×{clearedCount}` + pennant row (pennant tones
   from the board's content palette; each pennant's glyph = that cleared island's first-skill
   glyph — band-safe by construction), new-pennant spring (us-land 460ms) on victorious.
5. **Bottom bar**: Harbor button (always quiet white) + SET SAIL (state: `Looking…` dimmed /
   `Set sail` gold+ring / `Sail on` gold+ring). SET SAIL boots the gen duel via A-080's flag;
   Sail on runs A-081's `advanceUncharted` then transitions to the next island's Arriving.
6. **Palette**: the board DECLARES its additions — deep-sea group (7 hexes) into
   `src/theme/tokens.ts` as a theme group; terrain additions (trunk/grass-deeper/peak-cap/
   driftwood) joining the terrain group; pennant/label tones as CONTENT data beside the
   board constants, not theme. Hexes verbatim; no new undeclared literals.

## The doorway — Dock.tsx

The chip from the board's Doorway column, in the dock's chain-complete null-branch (it
REPLACES the "Every island cleared!" message, never joins it): OPEN (gold, ring, compass-?
disc, `SAIL PAST THE EDGE`) on first completion; RETURNING (no ring, pennant tally chip)
once `uncharted.clearedCount > 0`. The LOCKED pre-completion state is DEFERRED with the
chart-rebuild decision — while the chain is incomplete the dock is unchanged. Route via the
`services/flow.ts` graph, no route params.

## Acceptance criteria

- **AC-1**: State machine — arriving → ready (620ms), SET SAIL disabled while arriving,
  win → victorious (pennant lands, tally increments, wall thins), Sail on → next island
  arriving; a loss returns to ready with tally unchanged. No streak counter, no best-run
  (the board's red-flag rule, pinned by source-scan).
- **AC-2**: Transcription fidelity — unchartedBoard constants equal the board's measured
  values (frozen exact pins: state table, recipe table, marker/banner geometry, pennant
  tones); name banner ellipsizes a 24-char name at SE width without wrapping.
- **AC-3**: The dock chip appears ONLY when `chartProgress` is complete, in its two states,
  and the `chart-progress-presentation.test.ts:946-959` containment slice stays GREEN —
  `numberOfLines={1}` / `adjustsFontSizeToFit` still inside the null-branch. If the slice
  boundary itself must move, STOP and report (that is a D-17 re-baseline for the integrator,
  not you).
- **AC-4**: The authored chart is byte-untouched (`app/chart.tsx`, `chart/board.ts`,
  `VoyageMap` and every design-fidelity pin pass untouched); no gen id reaches any chart
  service (`chartNodes` never learns the frontier).
- **AC-5**: Offline whole-loop — with no network and no LLM anything, a captain completes
  arrive→duel→win→advance→arrive twice in a headless walk (A-078's local generator only).
