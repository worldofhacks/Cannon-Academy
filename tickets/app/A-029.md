## Context

The chart persists `captain.currentIsland`, but `initialDuelState` hardcodes Port Sumwich and 45
rival hull. The app therefore discards five existing `ENEMY_HULL_BY_ISLAND` values at the moment
the duel opens.

## Planning Decisions

- **[locked-decision]** The current island is required duel context. Invalid or fogged context
  returns to the chart rather than silently selecting Port Sumwich.
- **[locked-decision]** Hull, island name, and encounter seed inputs come from catalog/tuning
  contracts; screen code owns no island-specific number.
- **[locked-decision]** The unparameterized reducer initializer remains backward-compatible for
  frozen A-016 tests through A-039's adapter, while the live screen always supplies context.

## Acceptance Criteria

- **AC-1**: Given each catalog island as current, when a duel initializes, then `rivalHull` and
  `rivalMax` equal `ENEMY_HULL_BY_ISLAND[currentIsland]`.
- **AC-2**: Given two different island contexts with the same seed and actions, when initialized,
  then their non-hull deterministic state is equal while their tuned hull values differ.
- **AC-3**: Given missing, unknown, or fogged current-island context, when the screen opens, then it
  redirects safely to the chart and does not start a fallback duel.
- **AC-4**: Given a valid context, when the HUD and intro copy render, then they name the current
  island rather than the generic or hardcoded first island.
- **AC-5**: Given `RESET`, when a rematch starts, then the same island context is retained and a
  fresh duel id/seed is used.

## Test Plan

- Unit/property (deterministic): every island, invalid contexts, reset, and same-seed comparisons.
- Source guard: live entry passes current island; no Port Sumwich hull literal remains.
- Native smoke: duel on first and fifth island shows distinct names and hull totals.

## Definition of Done

- [ ] Tests are RED, independently reviewed, and frozen before implementation.
- [ ] Existing A-016 reducer invariants remain green.
- [ ] Local gates, native smoke, code review, and Security Agent review pass.
