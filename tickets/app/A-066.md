## Source of truth

Board: `Cannon Academy Island Encounter.dc.html` in Claude Design project
`88888c12-22e4-4781-b76f-a28110506499` — read it in full first (design MCP read tool via
ToolSearch). Five states (Entry / Riddle / Right / Gentle miss / Exit), five hosts with exact
shape recipes, and two amber-card rules that are law: **no wrong outcome** and **entry/exit
grow from the island's own position** (transform-origin 76%/34%).

## What this is

Shown once, the first time a captain lands on an island they earned. A chibi creature asks ONE
riddle whose answer is a number. Right pays +8 coins with a hop, two stars, and a three-coin
arc; wrong pays a shrug, the true answer shown plainly in amber-and-green, and the identical
`Onward!` tap. Then it never plays again for that island (`captain.seenEncounters` — the field
already exists on the captain, defaulted and normalized; do not touch the store/persistence
files).

## Band adjustment — the point of the ticket

The riddle's skill is the island's first band-eligible `rangeSkill` — the SAME eligibility rule
the entry cannon uses (`maxGradeForBand` / skill `minGrade`, failing closed on a missing band).
A K-1 captain arriving at Isla Products is asked a repeated-addition riddle; a g4_5 captain at
the same island gets multiplication; nobody is ever asked above their ceiling. The question is
produced by the REAL engine generator (`generateQuestion`) over an authored riddle pool, so
numbers, distractors, and the 4-choice grid are exactly as trustworthy as a duel's.

## Riddle content — a separate source, never the duel pools

Authored riddle templates live in `src/content/riddles/*.json` (one file per skill rung that an
arrival can ask, ≥2 riddles each), validated by the existing `templateSchema`, loaded by a new
`src/content/riddles.ts`. They are host-voiced word problems in the board's register ("I have 3
shells. I find 2 more. How many?") with `isWordProblem`/`readAloud` set. They are **never
merged into `TEMPLATE_POOLS`** — the frozen seed-replay contracts (spec(A-058:AC-5),
spec(A-014:*)) must stay byte-green, which they do automatically if the duel's pools are never
touched. Cover at minimum the arrival-entry skills reachable today: `add_within_10`,
`repeated_addition`, `multiplication_facts`-rung, the division rung Quotient Cove asks of older
bands, and the fraction rung — mirror however the entry-cannon eligibility enumerates them, and
write the enumeration into the test so a new island rung fails loudly instead of silently
having no riddles (fallback: skill has no riddle file → use its plain duel templates from a
LOCAL import, still not the shared pool object).

## Acceptance criteria

- **AC-1**: The five board states render pixel-faithfully at 375: entry grows 340ms from origin
  76%/34% with `Say hello` ringed; riddle shows bubble (19px, speaker slot 44pt) + four 72pt-tall
  tiles in a 2×2 grid, 34px numerals, no tile pre-ringed; right = host hop 620ms + two gold
  stars + three-coin arc (900ms, staggered 80ms) + ring burst + gold `+8 coins` strip + `Onward!`
  ringed; gentle miss = amber `~` on the chosen tile, green `✓` reveal on the true one, shrug
  520ms, parchment `No harm done` strip, identical `Onward!`; exit tucks 320ms back into the
  island.
- **AC-2**: The five hosts are built to the board recipes (crab, parrot, turtle, octopus, gull —
  body plans, eye/pupil construction, palette hexes) keyed by island id, within the stated shape
  budgets, bobbing at their stated loops.
- **AC-3**: Band-adaptivity proven at every band on every island that band can reach: the asked
  skill is the island's first band-eligible rangeSkill, the rendered text never contains `×` or
  `÷` for a k_1 captain, and a null/corrupt band asks nothing (fails closed, encounter completes
  latch-only).
- **AC-4**: No wrong outcome: correct pays exactly +8 coins ONCE per island — the latch is the
  idempotency (a replayed completion pays nothing) — wrong pays nothing, and both paths set the
  latch and end on the same `Onward!`. Amber, never red, anywhere in this component.
- **AC-5**: `Grown-ups: skip the island chats` (quiet underlined link, board copy exactly) sets
  the current island's latch and calls `onDone` — one tap, no confirmation, adult-quiet styling.
- **AC-6**: The public contract is exactly `EncounterCard({ islandId, onDone })`, self-contained
  (reads/writes the captain store itself); `src/services/encounter.ts` exports the pure pieces
  (`encounterSkillFor(islandId, band)`, `riddleFor(skill, rng)`, `completeEncounter(store,
  islandId, correct)`) and the tests drive THOSE for every behavioral AC.
