## Context

The current eight routes all have inbound edges. Harbor and rank add two more, and the finished
guided flow must remain exactly-once. This ticket owns only the route graph and compact chart-hub
affordances, not the screens themselves.

## Planning Decisions

- **[locked-decision]** The chart remains the hub; no separate title/menu screen is introduced.
- **[locked-decision]** Harbor, rank, training, gun deck, and fight are reachable without a hidden
  URL or developer-state injection.
- **[locked-decision]** Controls reuse the chart palette/plank depth and preserve the 64pt target
  floor; the sea map is not redesigned.

## Acceptance Criteria

- **AC-1**: Given every route file under `app/`, when the route graph is derived, then each
  child-facing route has at least one real inbound edge or is an intentional boot destination.
- **AC-2**: Given the chart, when a captain opens Harbor, rank, training, gun deck, or fight, then
  each destination is reachable in at most two taps and has a valid path back to the chart.
- **AC-3**: Given a captain who has not fought the guided duel, when boot routing resolves, then the
  tutorial still takes precedence; given it is complete, normal navigation never returns there.
- **AC-4**: Given a legacy/corrupt save with no equipped cannon, when routing resolves, then the gun
  deck repair path still takes precedence over chart navigation.
- **AC-5**: Given a 360pt-wide phone, when the hub controls render, then labels do not clip and
  targets remain at least 64pt without covering an island station.

## Test Plan

- Unit/source graph (deterministic): all routes, inbound/exit edges, resolver precedence, and target
  geometry constants.
- Native screenshots: 360×640 and 390×844 chart hub plus each round trip.

## Definition of Done

- [ ] Tests are RED, independently reviewed, and frozen before implementation.
- [ ] No route is documented as complete unless it is reachable without a deep link.
- [ ] Local gates, native smoke, code review, and Security Agent review pass.

## Out of Scope

Screen implementation, public leaderboard, redesigning the map, or deployment.
