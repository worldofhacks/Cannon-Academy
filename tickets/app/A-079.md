## Ruling

Amended D-17 + `docs/ENDLESS-ARCHIPELAGO-DESIGN.md` §2 S5 and the **bus law** (§1): the
captain's island-typed fields carry only authored ids or null, forever.

## The work

1. New captain field `uncharted?: { clearedCount: number; current: GenIslandDoc | null;
   next: GenIslandDoc | null; metLumen: boolean }` — the tolerated-as-absent pattern exactly
   as `seenEncounters`/`metRivals` landed: default in `emptyCaptain`, normalize in BOTH
   `normalizeCaptain` AND `migrateLegacyCaptain`, absent-tolerant, NOT in `isBaseCaptain`,
   **no SCHEMA_VERSION bump** (a bump without a migration arm deletes live saves —
   `persistence.ts:236-239`).
2. Normalizer validates the field with `genIslandSchema` (A-078): corrupt or band-mismatched
   docs → reset the slot to null (regenerable from seed), corrupt envelope → fresh
   `{clearedCount: 0, current: null, next: null, metLumen: false}` on the
   `normalizeMercyState` precedent (`persistence.ts:55-70`). clearedCount clamped to a
   non-negative integer.
3. **Bus-scrub hardening**: `normalizeCaptain` drops any non-catalog island string from
   `currentIsland` (→ null) and filters `unlockedIslands` to catalog ids — a hostile or
   bugged save can never put a gen id on the authored bus.
4. Store actions (`src/stores/player.ts`): `beginUncharted` (idempotent init from seed),
   `setUnchartedIslands(current, next)`, `advanceUnchartedState` (clearedCount+1, next→current,
   new next), `markLumenMet` — pure state moves, no service logic here.

## Acceptance criteria

- **AC-1**: A legacy captain JSON without `uncharted` hydrates with the default and
  round-trips WITHOUT the field being invented into old saves' semantics — proven through
  both `normalizeCaptain` and `migrateLegacyCaptain`.
- **AC-2**: Corrupt `uncharted` (wrong types, negative count, invalid doc) → fresh default;
  a band-mismatched island doc in a slot → that slot null, clearedCount preserved.
- **AC-3**: Bus law — `currentIsland: 'gen_isle_7'` and `'gen_isle_9'` inside
  `unlockedIslands` are scrubbed on hydrate; the frozen five-island specs
  (`grade-band-duel.test.ts:260-263` family) pass untouched.
- **AC-4**: `isBaseCaptain` is unchanged (source-scan) and SCHEMA_VERSION === 2 (pin).
