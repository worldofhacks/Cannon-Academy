## Context

The app branch has not integrated engine commit `91c013c` / T-036, so a range timeout still counts
as a wrong answer. Separately, `resolveUnlocks` can open Isla Products after a K-1 child masters
addition, and the range service does not filter skills by the selected grade band.

## Planning Decisions

- **[locked-decision]** Integrate the already-reviewed T-036 change rather than reimplementing it.
- **[locked-decision]** A grade pick is a safety ceiling for automatically offered content. A child
  is never served a skill whose `minGrade` exceeds their band maximum.
- **[locked-decision]** Mastery may unlock a cannon for an eligible skill but may not open an island
  whose curriculum begins above the captain's band.
- **[locked-decision]** Missing/invalid grade data or an explicitly requested above-ceiling skill
  makes `openDrill` throw `RangeError` synchronously. The range screen catches that typed refusal
  and returns to the safe picker; no fallback skill is selected.

## Acceptance Criteria

- **AC-1**: Given a timed-out range question, when it resolves, then attempts, correct count,
  mastery accuracy, and drill completion progress are unchanged, matching D-8 and T-036.
- **AC-2**: Given each grade band, when range skills are derived from any unlocked island, then
  every returned skill has `minGrade` at or below the band maximum and catalog order is preserved.
- **AC-3**: Given K-1 mastery of `add_within_10`, when unlocks resolve, then the earned range cannon
  is granted but Isla Products remains unavailable.
- **AC-4**: Given a band-eligible predecessor skill is mastered, when unlocks resolve, then the next
  eligible island still opens; existing higher-band placement unlocks are not revoked.
- **AC-5**: Given missing/corrupt grade data or a skill above the captain's ceiling, when a drill
  is requested, then `openDrill` throws `RangeError` synchronously and never opens a fallback
  drill.

## Test Plan

- Unit/property (deterministic): every grade band × island × skill, timeout sequences, and unlock

- Integration (deterministic): player-store tally applies the same filtered unlock result.
