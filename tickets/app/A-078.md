## Ruling

**D-17 as amended twice** (read both amendments in `tickets/app/OWNER-RULINGS.md`) and the
two-tier law of `docs/ENDLESS-ARCHIPELAGO-DESIGN.md` §1. You build Tier B's foundation: the
schema every generated island must pass, the board's design vocabulary as closed enums, and
the local deterministic generator that makes the frontier work with zero network.

## The board is pixel authority

`Cannon Academy Uncharted Sea.dc.html` in design project `88888c12-22e4-4781-b76f-a28110506499`
(read it via the claude_design MCP — load tools with ToolSearch "select:mcp__claude_design__read_file").
Its data script declares the canonical vocabulary. Transcribe exactly:

- **4 recipes** (`twin`, `atoll`, `cliff`, `crescent`) with their full geometry rows (shallowR,
  sandR, grass box, feature boxes, palms, rocks) — the ISLANDS table in the board script.
- **4 slots** `peak` (max 1 piece) / `ridge` (≤2) / `shore` (≤3, always exists) / `lagoon`
  (atoll + crescent only; pieces naming it are SKIPPED elsewhere, never relocated).
- **10 pieces** with their slot memberships (palms, waterfall, shipwreck, volcano, lighthouse,
  arch, tide pools, bone gate, beach hut, ice floe).
- **4 moods** (`dawn_gold`, `storm_slate`, `jungle_emerald`, `dusk_violet`) — each exactly six
  named token substitutions, hexes verbatim from the board's mood chips. Law from the board:
  a mood's sand stays lighter than its water; markers/banners/chrome never shift.
- **Name law**: `displayName` 1–24 chars, composed adjective+noun word lists, hard-reject >24.

## The schema — `src/content/genIsland.ts`

`genIslandSchema`, zod `.strict()`: `id` matching `/^gen_isle_[1-9][0-9]*$/` (template-literal
type `GenIslandId`, NEVER unioned with `IslandId`), `index` int ≥6, `seed` int, `displayName`,
`skills` nonempty array of `z.enum(SKILL_IDS)`, `recipe`, `pieces` (piece+slot pairs obeying
slot caps and recipe-lagoon law), `mood`, `presentationKind` (the 5-enum from
`src/content/generatedFleet.ts:44`), `hull` bounded int, `rivalDocId` (a shipped fleet doc id).
Glyph is NOT a field — derived `SKILL_GLYPH[skills[0]]`.

## The generator — `src/services/uncharted/generator.ts`

`generateIsland(seed, index, band)` — pure, deterministic (FNV-1a like `rivalVariant.ts`, no
Date/Math.random): skills rotated from the band's own atlas cells via `islandCurriculumFor`
(ceiling-safe by construction), recipe/mood/pieces dealt within the slot laws, name from the
word lists, rival dealt from the shipped 20-doc fleet pool filtered to known ships, hull a
clamped ramp above `ENEMY_HULL_BY_ISLAND.grandline` growing with index. Output always parses
its own schema (property-swept).

## Acceptance criteria

- **AC-1**: Schema strictness — unknown fields die at parse; a lagoon piece on `twin`/`cliff`,
  a 2nd peak piece, a 25-char name, a skill outside `SKILL_IDS`, an id outside the regex are
  all unrepresentable (each proven by a rejected fixture).
- **AC-2**: Determinism — same (seed,index,band) → deep-equal doc, 30-seed sweep × 3 bands ×
  indices {6,7,12,40}; every generated doc passes the schema and every skill sits at or under
  `maxGradeForBand(band)` — a k_1 doc never contains a ×/÷ skill, swept.
- **AC-3**: Vocabulary fidelity — recipes/pieces/slots/moods enums equal the board tables
  exactly (frozen exact-toEqual pin, board hexes verbatim).
- **AC-4**: `IslandId` untouched — no import of this module from `src/content/index.ts`,
  `src/engine/*`, or `src/services/{chart,duelContext,rewardSettlement,encounter}.ts`
  (source-scan spec), and `__tests__/content/schemas.test.ts` passes untouched.
