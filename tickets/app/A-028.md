## Context

The range picker is restricted to the current island. Later islands contain one skill each, so a
captain parked there sees one hard option even though easier, unlocked practice exists elsewhere.
The catalog already carries each skill's grade span; no new difficulty numbers are required.

## Planning Decisions

- **[locked-decision]** Show all age-eligible skills from all unlocked islands, grouped by island, and mark
  the current island. This preserves island identity while keeping warm-up practice reachable.
- **[locked-decision]** Difficulty labels are derived from catalog grade spans relative to the
  captain's band. They do not change authored math or pretend the unused template `difficulty`
  field is populated.
- **[locked-decision]** No timer is added to the range picker and no option above the selected band
  is offered automatically.

## Acceptance Criteria

- **AC-1**: Given a captain with multiple unlocked islands, when the training catalog is derived,
  then every distinct eligible skill across those islands appears exactly once with its island.
- **AC-2**: Given a later current island with one hard skill and an earlier eligible warm-up skill,
  when the picker renders, then both are selectable and the easier option is visible without
  changing the chart's current island.
- **AC-3**: Given a skill and grade band, when its label is derived, then the same inputs always
  produce the same child-readable difficulty word and accessibility description from catalog data.
- **AC-4**: Given a selected card, when a drill starts, then `openDrill` receives that exact
  island/skill pair and the summary credits that same skill.
- **AC-5**: Given no eligible training entries, when the screen renders, then it provides a safe
  return to the chart and never falls back silently to the Swivel Gun or another skill.

## Test Plan

- Unit (deterministic): catalog union/de-duplication, relative labels, exact selection mapping, and
  empty state.
- Source/presentation guard: all cards expose skill, island, and difficulty through text plus
  accessibility copy.
- Native visual evidence: 360×640 and 390×844 with at least three options.

## Definition of Done

- [ ] The cross-island picker follows the approved demo-ready plan.
- [ ] Tests are RED, independently reviewed, and frozen before implementation.
- [ ] Targets remain at least 64pt and use the existing 4pt spacing/token system.
- [ ] Local gates, native smoke, code review, and Security Agent review pass.

## Out of Scope

Authoring per-template difficulty tiers, adaptive IRT, changing mastery rates, and above-band
challenge mode.
