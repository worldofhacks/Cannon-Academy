## Context

Owner ruling **D-8** (2026-07-29): a burned fuse counts in neither `asked` nor `correct`, in the
aggregate and per-skill tally. The timeout panel's "Nothing lost" must be true.

App track mirrors this in `src/stores/duel.ts` under A-017. This ticket is the **range lane** —
`answerDrill(..., choiceIndex: null, ...)` today calls `applyAnswer(..., false)`, which raises
`attempts` and can lock a child out of a cannon they timed out toward. The lanes must not drift.

## Design call (named here)

**Timeout does not consume a drill slot.** `answered` / session `correct` / mastery are unchanged;
the same `current` question remains for a retry. The timeout is still appended to `log` (with
`choiceIndex: null`, `correct: false` as an event record — not a graded miss). No replacement
question is generated: retry-in-place is the cheapest reading of "nothing lost."

## Acceptance Criteria

- **AC-1**: Given a live session and prior mastery `M`, when `answerDrill(session, null, elapsed)`,
  then `mastery` equals `M` (neither `attempts` nor `correct` / `weightedCorrect` move).
- **AC-2**: Given the same call, then `answered` and session `correct` are unchanged, `complete`
  stays false when it was false, and `current` is still the same question (same `templateId` and
  `correctIndex`).
- **AC-3**: Given the same call, then `log` appends exactly one entry with `choiceIndex: null`,
  `correct: false`, and the given `elapsedMs`.
- **AC-4**: Given a wrong (non-null) choice, then behaviour is unchanged from T-017 AC-4 — a real
  miss still charges `attempts`.
- **AC-5**: Given T-017's frozen AC-5 pin that treated timeout as an incorrect attempt, then that
  pin is **amended** to D-8 (not deleted to silence a fail).
