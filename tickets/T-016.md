## Context

The top of the K-5 arc, and the band with the two hardest authoring constraints in the project.

Same file format and validation as T-014. Read that ticket's Context for the `Template` shape.
Word problems are permitted (all three skills have `minGrade >= 3`) and must set
`isWordProblem: true`.

**`div_facts` — the canonical rejection-sampling skill.** `{a} ÷ {b} = ?` requires exact
division, expressed as a constraint, not as truncation:

```json
{ "params": { "a": [1, 100], "b": [2, 10] }, "constraints": ["b != 0", "a % b == 0"], "answerExpr": "a / b" }
```

T-002's evaluator returns real division and throws `DIVISION_BY_ZERO`, so a template that omits
`a % b == 0` produces a fractional answer and fails AC-6 — which is exactly the intended
tripwire. Roughly `1/b` of draws pass, comfortably inside `MAX_PARAM_SAMPLE_ATTEMPTS` (100).

**`fractions_int` — every answer is a whole number.** PLAN.md commits to this so the four-choice
input needs no fraction keypad. Workable shapes, all integer-answerable:

- "How many `{d}`ths make `{n}` wholes?" → `answerExpr "n * d"`.
- Equivalent fractions, missing numerator: `"{a}/{b} = ?/{d}"`, constraint `"d % b == 0"`,
  `answerExpr "a * (d / b)"`.
- Fraction of a set: `"{a}/{b} of {c} = ?"`, constraint `"c % b == 0"`, `answerExpr "c / b * a"`.
- Whole-number result of adding like fractions: `"{a}/{b} + {c}/{b} = ? wholes"`, constraint
  `"(a + c) % b == 0"`, `answerExpr "(a + c) / b"`.
- Simplify to a whole: `"{a}/{b} = ?"`, constraint `"a % b == 0"`, `answerExpr "a / b"`.

**`multi_digit_order_ops` — precedence is the lesson.** `{a} + {b} × {c} = ?` and
`({a} + {b}) × {c} = ?` must appear as _distinct_ templates with distinct answers, and the
no-parentheses form's most valuable distractor is the wrong-order result `(a + b) * c`. Also:
multi-digit addition and subtraction with regrouping, two-digit × one-digit, and
`{a} × {b} - {c}` forms.

**Bounds:** every displayed number and every answer is a non-negative integer `<= 1000`.

## Planning Decisions

- `locked-decision` — **a floor of 8 templates per skill, no cap.** _Owner ruling D-1,
  2026-07-27._ PLAN.md:73 was amended at the Phase 1 checkpoint to read "a floor of 8 golden
  parameterized shapes per skill (the build target; 15–25 per skill is the post-MVP content
  goal, not a day-3 requirement)", removing the conflict with its own day-3 row.
  ARCHITECTURE.md §4.1 never stated a count. This ticket requires **≥8** per skill. **Closed.**
- `locked-decision` — every `fractions_int` answer is a whole number (PLAN.md commits to it as
  the reason Fraction Reef needs no special keypad).
- `proposed` — fractions are written in `text` with a `/` (e.g. `"3/4 of 12 = ?"`) rather than a
  stacked glyph. Presentation is a `src/components/**` concern and out of this swarm's scope; the
  content stays plain text.
- `scope-cut` — **"tap-the-picture" choices.** PLAN.md offers them as an alternative for
  fractions. They require an image asset pipeline and a non-numeric `Choice` shape, both out of
  this swarm's scope. Every choice here is numeric. Recorded in `.tdd-swarm/traceability.md`.
- `proposed` — the `<= 1000` display bound, for the same 2×2-grid legibility reason as T-015.
  Asserted by AC-6 so it cannot drift.
- `proposed` — for `multi_digit_order_ops`, at least one template must carry the wrong-order
  result as a _declared_ distractor. That is the single highest-value distractor in the skill,
  and AC-9 pins its presence rather than leaving it to authoring taste.

## Acceptance Criteria

- **AC-1**: Given each of the three JSON files, when parsed with `z.array(templateSchema)`, then
  parsing succeeds and each array has at least `8` entries.
- **AC-2**: Given every template across the three files, when inspected, then its `skill` equals
  the skill named by its own file, its `id` starts with that skill id followed by `_`, and all
  ids across the three files are pairwise unique.
- **AC-3**: Given every template, when its `text` is scanned, then every `{name}` token names a
  key declared in that template's `params`, and every declared param is referenced in `text`,
  `answerExpr`, or a `constraint` — no dead parameters.
- **AC-4**: Given every template, when 1,000 questions are generated from it via
  `generateQuestion` with seeds `1 … 1000`, then every call succeeds, every sampled param lies
  inside its declared inclusive range, every declared constraint evaluates `true`, the rendered
  `text` contains no `{` or `}`, `choices.length === 4`, all four choice values are pairwise
  distinct, and `choices[correctIndex].value` equals
  `evaluateNumber(template.answerExpr, params)`.
- **AC-5**: Given every `div_facts` template, when 1,000 samples are drawn, then no
  `DIVISION_BY_ZERO` error is ever raised and every correct answer is an integer — every
  division template constrains its divisor away from zero and its dividend to be exactly
  divisible.
- **AC-6**: Given all three files, when every correct answer and every numeric token in every
  rendered text is inspected over the sweep, then all are non-negative integers `<= 1000`. In
  particular every `fractions_int` answer satisfies `Number.isInteger`.
- **AC-7**: Given every `fractions_int` template, when 1,000 samples are drawn, then no rendered
  text and no choice **label** contains a `.` — no decimal ever reaches a child in this skill.
- **AC-8**: Given the `multi_digit_order_ops` file, when inspected, then it contains at least one
  template whose `text` has a `×` after a `+` with no parentheses, and at least one whose `text`
  parenthesises the addition — and for a fixed seed the two produce different correct answers for
  the same sampled `a, b, c`.
- **AC-9**: Given the `multi_digit_order_ops` file, when its templates are inspected, then at
  least one no-parentheses precedence template declares a distractor expression that is
  algebraically the wrong-order result (e.g. `"(a + b) * c"` where `answerExpr` is `"a + b * c"`).
- **AC-10**: Given every template with `isWordProblem: true`, when its rendered text is inspected
  over the sweep, then it is at most `160` characters and ends with `?`; and every template whose
  `text` contains alphabetic words beyond operator glyphs and unit nouns has
  `isWordProblem: true`.
- **AC-11**: Given the same 1,000-sample sweep per template, when the number of samples in which
  `describeDistractorSources` (T-005 AC-14) reports a `'ladder'` source is counted, then it is fewer
  than `250` of the 1,000.
- **AC-12**: Given each template, when a single generation is run at one fixed seed, then the
  test asserts that generation's rendered `text` and correct answer value against **literal
  expected values written by the test author** (e.g. `expect(v).toBe(9)` for `72 ÷ 8`), pinning
  the arithmetic independently of the evaluator.
- **AC-13**: Given the three files collectively, when distinct `text` skeletons (each `text` with
  every `{…}` replaced by `#`) are counted per skill, then there are at least `5` per skill.
- **AC-14**: Given every template, when `generateQuestion` is called across seeds `1 … 200`, then
  no `CONSTRAINTS_UNSATISFIED` error is raised — every template, including the divisibility-
  constrained ones, samples inside `MAX_PARAM_SAMPLE_ATTEMPTS`.
- **AC-15**: Given every template, when inspected, then it declares at least `3` distractor
  expressions, none textually identical to `answerExpr` or to a sibling distractor.
