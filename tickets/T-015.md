## Context

The first band where **word problems are permitted** — all three skills have `minGrade >= 2`, so
`symbolicOnly` is `false` (T-006). A word-problem template must set `isWordProblem: true`, and
may set `readAloud: true` (the field is carried for a future TTS pass; nothing in this swarm
reads it).

Same file format and validation as T-014. Read that ticket's Context for the `Template` shape.

**Per-skill authoring rules:**

| skill                 | answer                         | required constraints                                                                        |
| --------------------- | ------------------------------ | ------------------------------------------------------------------------------------------- |
| `place_value_compare` | non-negative integer `<= 1000` | every displayed number `0 … 1000`                                                           |
| `two_step_add_sub`    | non-negative integer `<= 100`  | **both** the intermediate result and the final answer `>= 0`; nothing displayed exceeds 100 |
| `mult_facts`          | non-negative integer `<= 100`  | factors `0 … 10`                                                                            |

**`place_value_compare` needs care.** Every choice is a number, so "which is greater?" shapes
only work when three _plausible numeric_ distractors exist. Prefer numeric-answer shapes:
"What is the value of the tens digit in `{a}`?", "`{a}` rounded to the nearest ten = ?",
"How many tens are in `{a}`?", "Which is greater, `{a}` or `{b}`?" (answer `max(a,b)`, with the
loser plus near-misses as distractors — use sparingly), "`{a}` is ? more than `{b}`".

**`two_step_add_sub` is the two-step trap.** `{a} + {b} - {c} = ?` must constrain
`a + b - c >= 0` _and_ keep the intermediate `a + b` inside the stated bound. A template that can
produce a negative intermediate teaches a K-3 child an operation they have not been taught.

**`mult_facts`**: `{a} × {b} = ?`, missing factor `{a} × ? = {c}`, arrays/groups as word problems
("`{a}` crates hold `{b}` cannonballs each. How many cannonballs?"), doubling, and ×10 patterns.
Use the character `×`, not `*` or `x`, in `text`. (`answerExpr` still uses `*` — that is the
evaluator's grammar, not display text.)

**Distractor patterns**: off-by-one and off-by-ten; wrong-operation (`a + b` for a multiplication
template, guarded for plausibility); adjacent-fact errors (`a * b + a`, `a * b - b`); and for
place value, the transposed-digit and wrong-place-value near-misses PLAN.md names.

## Planning Decisions

- `locked-decision` — **a floor of 8 templates per skill, no cap.** _Owner ruling D-1,
  2026-07-27._ PLAN.md:73 was amended at the Phase 1 checkpoint to read "a floor of 8 golden
  parameterized shapes per skill (the build target; 15–25 per skill is the post-MVP content
  goal, not a day-3 requirement)", removing the conflict with its own day-3 row.
  ARCHITECTURE.md §4.1 never stated a count. This ticket requires **≥8** per skill. **Closed.**
- `locked-decision` — a word problem is legal here only with `isWordProblem: true`; T-019
  cross-checks every template's flag against its skill's `symbolicOnly`.
- `proposed` — display bounds (`<= 1000` for place value, `<= 100` elsewhere) are chosen to keep
  every number readable in a 2×2 answer grid at ≥64pt (ARCHITECTURE.md §3.6) and inside grade-2–3
  curriculum. Neither document states a bound; the bound is asserted by AC-6 so it cannot drift.
- `proposed` — word-problem text stays under ~140 characters and uses only concrete nouns from
  the naval setting, so a grade-2 reader is not gated by vocabulary. Pinned by AC-9.
- `proposed` — `×` in display text, `*` in `answerExpr`. Children read `×`; the evaluator's
  grammar (T-002) does not include it.

## Acceptance Criteria

- **AC-1**: Given each of the three JSON files, when parsed with `z.array(templateSchema)`, then
  parsing succeeds and each array has at least `8` entries.
- **AC-2**: Given every template across the three files, when inspected, then its `skill` equals
  the skill named by its own file, its `id` starts with that skill id followed by `_`, and all
  ids across the three files are pairwise unique.
- **AC-3**: Given every template whose `text` contains any alphabetic word other than the skill's
  operator symbols, when inspected, then `isWordProblem` is `true`; and given every template with
  `isWordProblem: true`, then its skill's `symbolicOnly` is `false` in the catalog.
- **AC-4**: Given every template, when its `text` is scanned, then every `{name}` token names a
  key declared in that template's `params`, and every declared param is referenced in `text`,
  `answerExpr`, or a `constraint` — no dead parameters.
- **AC-5**: Given every template, when 1,000 questions are generated from it via
  `generateQuestion` with seeds `1 … 1000`, then every call succeeds, every sampled param lies
  inside its declared inclusive range, every declared constraint evaluates `true`, the rendered
  `text` contains no `{` or `}`, `choices.length === 4`, all four choice values are pairwise
  distinct, and `choices[correctIndex].value` equals
  `evaluateNumber(template.answerExpr, params)`.
- **AC-6**: Given the same sweep, when every correct answer and every numeric token in the
  rendered text is inspected, then all are non-negative integers; for `place_value_compare` all
  are `<= 1000`; for `two_step_add_sub` and `mult_facts` all are `<= 100`.
- **AC-7**: Given every `two_step_add_sub` template, when 1,000 samples are drawn, then the
  intermediate result of the first operation — computed in the test from the sampled params — is
  non-negative in every sample. No two-step template may pass through a negative.
- **AC-8**: Given every `mult_facts` template, when 1,000 samples are drawn, then every factor
  appearing in the rendered text is an integer in `[0, 10]`, and every `text` uses the character
  `×` and never `*` or a lowercase `x` as the operator.
- **AC-9**: Given every template with `isWordProblem: true`, when its rendered text is inspected
  over the sweep, then it is at most `140` characters, ends with `?`, and contains at least one
  `{…}`-substituted numeral.
- **AC-10**: Given the same 1,000-sample sweep per template, when the number of samples in which
  `describeDistractorSources` (T-005 AC-14) reports a `'ladder'` source is counted, then it is fewer
  than `250` of the 1,000.
- **AC-11**: Given each template, when a single generation is run at one fixed seed, then the
  test asserts that generation's rendered `text` and correct answer value against **literal
  expected values written by the test author** (e.g. `expect(v).toBe(56)` for `7 × 8`), pinning
  the arithmetic independently of the evaluator.
- **AC-12**: Given the three files collectively, when distinct `text` skeletons (each `text` with
  every `{…}` replaced by `#`) are counted per skill, then there are at least `5` per skill; and
  each file contains at least one `isWordProblem: true` template and at least one symbolic one.
- **AC-13**: Given every template, when `generateQuestion` is called across seeds `1 … 200`, then
  no `CONSTRAINTS_UNSATISFIED` error is raised — every template samples inside
  `MAX_PARAM_SAMPLE_ATTEMPTS`.
- **AC-14**: Given every template, when inspected, then it declares at least `3` distractor
  expressions, none textually identical to `answerExpr` or to a sibling distractor.
