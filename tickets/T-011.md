## Context

One pure function, called once at onboarding, that turns the grade picker's answer into a
starting game state. It is small but load-bearing: it is the difference between a 5th grader's
first duel being multiplication and it being `3 + 4`.

```ts
export interface Placement {
  readonly maxGrade: number;                       // 1 | 3 | 5
  readonly unlockedCannons: readonly CannonId[];   // ascending by minGrade, then id
  readonly unlockedIslands: readonly IslandId[];   // ascending by island order
  readonly botAccuracyBand: { readonly min: number; readonly max: number };
}
export function resolvePlacement(band: GradeBand): Placement;
```

**Rules:**

- `maxGrade`: `k_1 → 1`, `g2_3 → 3`, `g4_5 → 5` (the top grade of each PLAN.md band).
- **Cannons:** every cannon whose `unlock.kind` is `starter` or `range` and whose
  `minGrade <= maxGrade`. Cannons with `unlock.kind === 'chest'` are never pre-unlocked — the
  Nine-Pounder stays a reward.
- **Islands:** every island for which at least one `rangeSkills` entry has
  `skill.minGrade <= maxGrade`. The result must be a contiguous prefix of islands by `order`.
- **Bot band:** `BOT_ACCURACY_BAND_BY_GRADE[band]` from `tuning.ts`.

## Planning Decisions

- `proposed` — "up to the player's band" is read as `cannon.minGrade <= maxGrade` (the gun is
  *reachable* at this band) rather than `cannon.maxGrade <= maxGrade` (the gun is *outgrown*).
  The latter would deny a 3rd grader the Mortar (grades 3–4), contradicting "a 5th grader begins
  at multiplication, not 3+4".
- `proposed` — chest-drop cannons are excluded from placement. PLAN.md assigns the Nine-Pounder
  to a chest drop; pre-granting it would delete a reward moment.
- `proposed` — the island rule uses the *minimum* grade of an island's range skills, so an
  island appears as soon as any of its content is age-appropriate. AC-6 additionally requires
  the result to be a contiguous prefix by `order`, which the catalog's grade ordering makes true
  and which the test pins so a future island reordering cannot create an unreachable gap.
- `open-question` — "sets starting bot difficulty". PLAN.md says the picker sets it but never
  says to what. This ticket returns the band's `BOT_ACCURACY_BAND_BY_GRADE` entry (T-004),
  whose values are themselves an open question there; nothing is invented here.

## Acceptance Criteria

- **AC-1**: Given each `GradeBand`, when `resolvePlacement` is called, then `maxGrade` is `1`
  for `k_1`, `3` for `g2_3`, and `5` for `g4_5`.
- **AC-2**: Given `k_1`, when placed, then `unlockedCannons` contains exactly `swivel_gun`,
  `culverin`, `six_pounder`, and `chain_shot` — the two starters plus the two grade-1 range guns.
- **AC-3**: Given any band, when placed, then `unlockedCannons` never contains `nine_pounder`
  (its `unlock.kind` is `chest`).
- **AC-4**: Given `g4_5`, when placed, then `unlockedCannons` contains every cannon whose
  `unlock.kind` is `starter` or `range` — all nine of them — and `unlockedIslands` contains all
  five islands.
- **AC-5**: Given `g2_3`, when placed, then `unlockedCannons` includes `twelve_pounder` and
  `mortar` and `double_broadside`, and excludes `powder_keg` and `long_nine`.
- **AC-6**: Given each band, when `unlockedIslands` is mapped to island `order` and sorted, then
  the result is exactly `[0, 1, …, n-1]` for some `n >= 1` — a contiguous prefix with no gaps —
  and `port_sumwich` is present for every band.
- **AC-7**: Given `k_1`, when placed, then `unlockedIslands` is exactly `[port_sumwich]`.
- **AC-8**: Given each band, when `botAccuracyBand` is read, then it deeply equals
  `BOT_ACCURACY_BAND_BY_GRADE[band]`, and `0 < min < max <= 1`.
- **AC-9**: Given the same band, when `resolvePlacement` is called 100 times, then all results
  are deeply equal, and mutating a returned array does not affect a subsequent call's result.
- **AC-10**: Given a value outside `GradeBand` passed as `band`, when called, then it throws an
  `Error` naming the invalid band — the function is total over its declared union and loud
  outside it.
- **AC-11**: Given each band, when the placement's cannons are cross-checked against the
  catalog, then every returned `CannonId` exists in `cannons` and no id is duplicated; likewise
  for `unlockedIslands`.

## Test Plan

- Unit (deterministic): AC-1, AC-2, AC-4, AC-5, AC-7 — the full band × placement table. Three
  bands, exhaustive expected sets, so a catalog edit that silently changes a band's starting
  loadout fails here.

- Unit (deterministic): AC-8 — bot band pass-through.
- Unit (deterministic): AC-9, AC-10 — purity/immutability and the invalid-band error.
