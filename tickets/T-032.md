## Context

Wave-3 integration found that `resolvePlacement` pre-granted every `starter` **or `range`**
cannon at or below the band, so `resolveUnlocks` had nothing left to award at `g4_5`. Owner
ruling **D-6** (2026-07-28) closes the open question:

> **Placement pre-unlocks ISLANDS to the player's band, and starter cannons only. Every
> non-starter cannon is earned** through its declared `unlock`.

`resolvePlacement('k_1')` today returns four cannons including `chain_shot` and `six_pounder`
(`unlock.kind === "range"`). After this ticket it returns exactly the two starters. Existing
T-011 tests that assert four cannons **must fail and be rewritten** — that is the change, not
collateral. T-011's AC-2 / AC-4 / AC-5 and Rules section were amended to match D-6 in the same
dispatch; this ticket owns the suite rewrite, the composition proof, and the `placement.ts` fix.

`mastery.ts` needs no code change — its delta semantics were already correct. The composition
suite lives in a **new** test file so T-010's frozen suite stays untouched.

## Planning Decisions

## Acceptance Criteria

- **AC-1**: Given each `GradeBand`, when `resolvePlacement` is called, then every id in
  `unlockedCannons` names a catalog cannon whose `unlock.kind === 'starter'`, and no id with
  `unlock.kind === 'range'` or `'chest'` appears.
- **AC-2**: Given `k_1`, when placed, then `unlockedCannons` contains exactly `swivel_gun` and
  `culverin` (order-independent).
- **AC-3**: Given `g2_3` and `g4_5`, when placed, then `unlockedCannons` equals the catalog set of
  starters with `minGrade <= maxGrade` for that band — today the same two starters as `k_1` — and
  specifically excludes `six_pounder`, `chain_shot`, `twelve_pounder`, `mortar`,
  `double_broadside`, `powder_keg`, `long_nine`, and `nine_pounder`.
- **AC-4**: Given each band, when `unlockedIslands` is inspected, then the T-011 island rules still
  hold: contiguous prefix by `order`, `port_sumwich` always present, `k_1 → [port_sumwich]`,
  `g4_5` contains every island. Island pre-unlock is unchanged by D-6.
- **AC-5**: Given `g4_5`, when `P = resolvePlacement('g4_5')` and every skill is at or above
  `MASTERY_THRESHOLD`, when `resolveUnlocks` is called with `unlockedCannons: P.unlockedCannons`
  and `unlockedIslands: P.unlockedIslands`, then the returned `cannons` set equals every catalog
  cannon whose `unlock.kind === 'range'` (all seven) — proving mastery still pays at the top band.
- **AC-6**: Given `k_1`, when `P = resolvePlacement('k_1')` and `add_within_20` plus
  `sub_within_20` are mastered (with other skills empty), when `resolveUnlocks` is called with
  `P`'s unlocked sets, then the returned `cannons` include `six_pounder` and `chain_shot` and do
  not re-list the starters.
- **AC-7**: Given the amended T-011 cannon ACs (AC-2, AC-4, AC-5), when the placement suite is
  run, then those criteria pass under the starters-only rule — the old four-cannon / nine-cannon
  expectations are gone from `__tests__/engine/placement.test.ts`.
