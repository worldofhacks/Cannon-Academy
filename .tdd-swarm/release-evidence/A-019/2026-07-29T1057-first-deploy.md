## Open production warning

The app renders and navigation succeeds, but the production console records React minified error
`#418` on cold hydration. React defines this as server-rendered HTML not matching the client, after
which the client regenerates that subtree. This means A-019 AC-4's stricter “no console errors”
clause is not yet met even though the release is usable.

The warning is reproducible on a cold direct `/chart` request and a subsequent reload. Local
development did not emit it. Initial source tracing points to width-dependent server/client markup
in the splash/layout path, but no production fix is authorized by this evidence-only ticket.
